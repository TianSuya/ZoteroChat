## 写一份新的

用这个结构，简短即可：

```markdown
# NNNN. 标题

**状态**：已采纳 / 已废弃 / 被 NNNN 取代
**日期**：YYYY-MM

## 背景

什么问题逼出了这个决策。

## 决策

做了什么。

## 理由

为什么是它，以及**放弃的选项各自因为什么被放弃**——这部分最值钱。

## 代价

接受了什么。诚实写，别粉饰。

## 证据

怎么验证的。探针输出、日志、源码位置。
```
