## Updating screenshots

Capture the actual application with a public paper and synthetic questions. Exclude credentials, private library information, debug probes, and desktop clutter. Prefer a clean rectangular capture to a transparent cutout, and check readability on both light and dark backgrounds.

Keep the three-part sequence: reader layout, selection interaction, and a real answer. Preserve enough detail to inspect the UI and equations. Do not describe a single answer as a multi-turn conversation. Keep the UI language and operating-system chrome consistent across a set. English captures can replace or supplement the current Chinese examples when available.

The current crops remove exterior decoration but do not improve the source resolution or recreate missing interface content. Replace them with fresh captures when the UI changes; do not synthesize application behavior or model answers for screenshots.
